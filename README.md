# SOC Phishing Attack Simulator

An interactive, full-stack cybersecurity simulation tool where users navigate real-world phishing scenarios while an automated state machine calculates risk and logs audit trails.

### Backend(Flash)
bash
cd backend
pip install flask flask-cors
python app.py

### Frontend (React)
Bash
cd frontend
npm install
npm start
